# Recording Merchandise Purchases (live presentation)

`index.html` is a self-contained slide app for presenting purchase entries under the perpetual inventory system:
(a) cash purchase, (b) purchase on account 2/10, n/30 and its payment, (c) freight FOB shipping point,
(d) purchase return, (e) purchase allowance, and the Merchandise Inventory T-account.

Open it in a browser, or drag this folder onto Netlify Drop.

| Key | Action |
|---|---|
| Right arrow, Space, Page Down (clicker) | Next part of the slide |
| Left arrow, Page Up | Previous part |
| Down / Up arrow | Next / previous slide |
| A | Show every part of the current slide |
| N | Speaker notes |
| M | Slide list |
| F | Full screen |

Each slide's address is `#slide-N`, so you can link to or reopen a specific slide.
